# Generating Bliss Symbol Explanations Data

`public/data/bliss_symbol_explanations.json` contains the Bliss symbol vocabulary used by this
project, including glosses, part-of-speech labels, semantic explanations, and symbol compositions.
This file is generated from a source dictionary provided by the
[bliss-svg-builder](https://github.com/hlridge/bliss-svg-builder) project. The source dictionary
is not committed to this repository due to licensing restrictions, so when a new Bliss symbol set
is released, the file must be regenerated by following the steps below.

Known expected data gaps from the current dataset dated on 2026-05-13 (use as a baseline for comparison):

- 9 items missing `bciAvId` (ids: 5844, 5995, 6435, 6436, 6437, 6438, 6439, 6440, 6441)
- 1 item missing `explanation` (id: 6330)

## Prerequisites

- Node.js (already required by the project)
- Script: `scripts/generate_bliss_symbol_explanations.js`

## Steps

### Step 1 — Download the input file

Download the source dictionary from
[Google Drive](https://drive.google.com/file/d/1UyhCDYeEe-OzgM7aWWCpBoEog9H9D5RL/view?usp=drive_link).

Save it locally, for example at `scripts/data/bliss_dictionary_<date>.json`. When a new symbol set is
released, an updated version of this file will be shared.

### Step 2 — Run the script

```bash
node scripts/generate_bliss_symbol_explanations.js \
  <path/to/bliss_dictionary_<date>.json> \
  public/data/bliss_symbol_explanations.json [--verbose]
```

Example:

```bash
node scripts/generate_bliss_symbol_explanations.js \
  scripts/data/bliss_dictionary_20260513.json \
  public/data/bliss_symbol_explanations.json
```

Pass `--verbose` to include additional diagnostic warnings in the report (special code
segments, missing `isChar`, missing `explanation`). These warnings don't affect the data
in the generated data file.

### Step 3 — Review the processing report

The script prints a report after completion. Check it before committing the output.

**Errors** — always shown; require investigation before committing:

- `Missing Code Report` — composed symbol (`isChar=false`) has no `code` field
- `Missing ID Reference Report` — a symbol references an ID that does not exist in the dataset
- `Non-Character Reference Report` — a symbol's `code` references an item that is not a base character

**Always-visible warnings** — notable data gaps, shown by default:

- `Items missing "bciAvId"` — known gaps in source data
- `Items missing "pos"` — known gaps in source data

**Verbose-only warnings** — shown only with `--verbose`:

- `Special Code Segment Report` — items with non-standard composition code tokens
- `Items missing "isChar"` — defaulted to `false`
- `Items missing "explanation"` — known gaps in source data

## Reference: Input File Data Structure

The input file is a JSON object with a single `data` array. Each element describes one Bliss symbol.

Root structure:

```json
{
  "data": [ /* array of BlissItem */ ]
}
```

`BlissItem` fields:

| Field | Type | Script usage | Description |
| --- | --- | --- | --- |
| `id` | number | Required | Unique numeric ID (primary key) |
| `isChar` | boolean | Required | `true` = base character; `false` = composed word |
| `gloss` | string | Required | English label(s) for the symbol |
| `code` | string | Required for composed symbols | Composition code — `B`-prefixed numeric IDs joined by `/` or `;`, e.g. `B206/B1021/B710` |
| `bciAvId` | number | Processed, optional | BCI-AV database ID; passed to output, warned if missing |
| `pos` | string | Processed, optional | Part of speech (e.g. `noun`, `verb`); passed to output, warned if missing |
| `explanation` | string | Processed, optional | Semantic explanation; passed to output, warned if missing |
| `filename` | string | Not used | SVG filename — present in source data, not read by the script |
| `isWord` | boolean | Not used | Present on composed words — not read by the script |
| `derivationParts` | array | Not used | Sub-component metadata — present in source data, not read by the script |

Example — a base character (`isChar: true`):

```json
{
  "id": 1,
  "gloss": "exclamation mark",
  "filename": "exclamation_mark",
  "isChar": true,
  "pos": "expression",
  "code": "VL6:0,8;DOT:0,16",
  "bciAvId": 8483,
  "explanation": "punctuation mark - 1. used as punctuation in symbol sentences; ...",
  "derivationParts": []
}
```

Example — a composed word (`isChar: false`):

```json
{
  "id": 1164,
  "gloss": "abortion (induced)",
  "filename": "abortion_(induced)",
  "isChar": false,
  "pos": "noun",
  "code": "B206/B1021/B710",
  "bciAvId": 12323,
  "explanation": "to cause + miscarriage,abortion (spontaneous)",
  "isWord": true,
  "derivationParts": [
    {
      "id": "B206",
      "type": "CODE",
      "code": "RT8E:0,8",
      "gloss": "cause",
      "bciAvId": 13134
    },
    {
      "id": "B2016",
      "type": "CODE",
      "code": "B1021/B710",
      "gloss": "miscarriage, abortion (spontaneous)",
      "bciAvId": 15477
    }
  ]
}
```

## Reference: Output Data Structure

The output file is a JSON array with one object per symbol.

| Field | Type | Present when | Description |
| --- | --- | --- | --- |
| `id` | number | Always | Symbol ID (from input `id`) |
| `bciAvId` | number | Source has it | BCI-AV-ID |
| `gloss` | string | Always | English label(s) |
| `pos` | string | Source has it | Part of speech |
| `explanation` | string | Source has it | Semantic explanation |
| `isCharacter` | boolean | Always | `true` = base character (renamed from input `isChar`) |
| `composition` | array | `isCharacter` is `false` | Flat array of base character IDs and separators |

`composition` is a flat array of numeric base-character IDs and separator strings (`"/"` or `";"`).
The script resolves composed symbols recursively until only base characters remain.

Example output for a base character:

```json
{
  "id": 1,
  "bciAvId": 8483,
  "gloss": "exclamation mark",
  "pos": "expression",
  "explanation": "punctuation mark - ...",
  "isCharacter": true
}
```

Example output for a composed word:

```json
{
  "id": 1164,
  "bciAvId": 12323,
  "gloss": "abortion (induced)",
  "pos": "noun",
  "explanation": "to cause + miscarriage,abortion (spontaneous)",
  "isCharacter": false,
  "composition": [206, "/", 1021, "/", 710]
}
```
