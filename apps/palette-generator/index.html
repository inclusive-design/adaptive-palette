How to specify matches

List the items to search for in the "Search for matches:" text box above. Each line corresponds to a row in the generated palette. Items are separated by spaces and each item specifies a single cell. Each item is one of:

  • BLANK (all capitals), for a empty blank cell,
  • BCI AV ID, one of the official identifiers of a Bliss character or Bliss word (Bliss symbol),
    • The cell's label is the gloss associated with the Bliss symbol.
  • A gloss. Use GLOSS:gloss:GLOSS. The glossary is searched for glosses that match, or for a partial or exact match with the gloss of an individual Bliss symbol. Mutitple matches are possible, but only the first match is displayed in the preview.
    • The label is the given label to be displayed and exported.
  • An svg-builder string, as defined by the bliss-svg-builder, that defines the SVG image to use for the symbol,
    • The cell will have no label.

Except for BLANK cells, you can optionally specify a label for each type of item. Append LABEL:label_text:LABEL to the end of the item. The label_text have spaces. Some examples:

  • 25605LABEL:ruin:LABEL will find the symbol whose BCI AV ID is "25605". The cell's label is "ruin".
    • If the LABEL:ruin:LABEL is not appended, the label is the gloss for 25605, namely, "dilapidated, ruined (building) (1)".
  • GLOSS:indicator (action):GLOSSLABEL:verb:LABEL will find the symbol whose gloss is "indicator (action)". The cell's label is "verb".
    • If the LABEL:verb:LABEL is not appended, the label is the matched gloss text, i.e. "indicator (action)".
  • SVG:13166;9011:SVGLABEL:children:LABEL will generate the SVG image that combines the symbols that mean "child" and "plural". The cell's label is "children". 13166 and 9011 are the BCI AV IDs for "child" and "indicator (plural)", respectively.
  • SVG:B220;B99:SVGLABEL:children:LABEL will also generate the SVG image that combines the symbols that mean "child" and "plural". However, the identifiers in this SVG builder string are blissary IDs (the "B" prefix followed by the blissary ID number).

When the page loads the first time, the above examples are shown in the "Search for matches" text box. Press "Generate palette" button to preview the palette and see the list of matehes below the preview.

SVG Builder String Syntax

The two main parts of an SVG builder string are the BCI-AV-ID numbers and several kinds of separators. The separator characters and how they affect the rendering of the symbols are noted below. The terminology is taken from The Fundamental Rules of Blissymbolics, Sections 3.3, 3.6, and 3.7.

/ - forward slash
Normal space between Bliss symbols in a Bliss-word (BLISSYMBOL HALF SPACE).
Example: 12378/25582 (animal + mask)
// - double forward slash
Normal space between Bliss words in a Bliss sentence (BLISSYMBOL FULL SPACE).
Example: 12378//25582 (animal mask)
; - semi-colon
Superimpose the symbol following the semi-colon onto the previous symbol. Used frequently for indicators.
Example: 12378;9011/25582 (animals + mask)
;; - double semi-colon
Superimpose the symbol following the double semi-colon onto the classifier symbol in the Bliss word composed by preceeding symbols. Used frequently for indicators.
Example: 12378;9011/25582 (animals + mask)
RK:-2 - relative kerning
Quarter space between symbols (BLISSYMBOL QUARTER SPACE)
Example: 14164/RK:-2/16164 (feeling + illness)
X<single letter> - letter
X must be followed by a single letter, e.g. "a". The result is the Blissymbol for that letter.
Example: XH/Xo/Xl/Xl/Xi/Xs
